Display & text

						

							GET /api/settings
							

								
Current device settings as JSON (mode, text, speed, WiFi status, access control, ...).

								
curl http://192.168.1.50/api/settings -H "X-OTA-Password: splitflap"

							

						

						

							POST /api/settings
							

								
Change settings, like the main form. animationMode (simultaneous/left-to-right/right-to-left/outside-in/inside-out) and animationStaggerMs (0-1000) control the staggered start per unit; the default is simultaneous.

								
curl -X POST http://192.168.1.50/api/settings \
  -H "X-OTA-Password: splitflap" \
  --data "deviceMode=text&inputText=HELLO&alignment=center&flapSpeed=80&animationMode=left-to-right&animationStaggerMs=200"

							

						

						

							POST /api/text
							

								
Set text for automations (webhooks, Home Assistant, Shortcuts): without duration permanently, with duration (seconds) temporarily.

								
# Permanently
curl -X POST http://192.168.1.50/api/text -H "X-OTA-Password: splitflap" --data "text=HELLO WORLD"

# For 10 seconds, then back to the previous display
curl -X POST http://192.168.1.50/api/text -H "X-OTA-Password: splitflap" --data "text=BRB&duration=10"

							

						

						

							GET/POST /api/rotation-items
							

								
All rotation entries including their own alignment and animation (alignment/animationMode/animationStaggerMs; empty/-1 = default). POST replaces the whole list with a JSON array (Content-Type: application/json, at most 8000 bytes).

								
curl http://192.168.1.50/api/rotation-items -H "X-OTA-Password: splitflap"

curl -X POST http://192.168.1.50/api/rotation-items -H "X-OTA-Password: splitflap" \
  -H "Content-Type: application/json" --data '[{"type":"clock","format":"HH:mm","durationSeconds":10}]'

							POST /api/wifi?action=set-hostname|set-router-hostname

Security

						

							POST /api/ota-password
							

								
Change the password and/or the opened categories; currentPassword is always required. A new password needs at least 8 characters; an empty newPassword= turns protection off. The device only stores a hash of the password. Send every category that should stay open (e.g. accessControlText=on); a missing one becomes protected.

								
# Change the password only
curl -X POST http://192.168.1.50/api/ota-password \
  --data "currentPassword=splitflap&newPassword=myNewPassword"

# Turn protection off globally
curl -X POST http://192.168.1.50/api/ota-password \
  --data "currentPassword=splitflap&newPassword="

# Open up /api/text, everything else stays protected
curl -X POST http://192.168.1.50/api/ota-password \
  --data "currentPassword=splitflap&accessControlText=on"

  -H "X-OTA-Password: splitflap" --data "size=$SIZE"

curl -X POST http://192.168.1.50/api/firmware-chunk \
  -H "X-OTA-Password: splitflap" -H "Content-Type: application/octet-stream" \
  --data-binary @chunk_aa

curl -X POST http://192.168.1.50/api/firmware-finish -H "X-OTA-Password: splitflap"
